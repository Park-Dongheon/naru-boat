# NARU MOONBOAT

개목나루 무장애 문보트의 탑승자 모바일 경험과 운영 관제 대시보드를 하나의 반응형 프론트엔드로 구현한 프로젝트입니다.

## 실행

```bash
npm install
npm run dev
```

프로덕션 빌드와 정적 검사는 다음 명령으로 확인합니다.

```bash
npm run lint
npm run build
```

## 구현 범위

- 탑승자 정보, 날짜·회차, 보트 종류와 탑승 인원 선택
- 휠체어, 경사판, 보호자 동승, 직원 지원, 음성·큰 글자 안내 요청
- 개인정보 동의와 예약 변경·취소
- 출발 전 안전 안내 확인
- GPS 위치, 관광 콘텐츠 자동 안내, 운항 상태
- 예약·현장 확인·탑승 진행 상태
- 위험구역 및 다감각 안전 안내
- 글자 크기, 움직임, 자동 음성 접근성 설정
- 문보트 실시간 관제와 장치 제어
- 예약 승인·취소, 이용자 안내, 보트 배정
- 보트 유형·정원·접근성·운영 여부와 예약 회차 설정
- 정비시간, 배터리 경고 기준과 기상특보 예약중지 정책
- 위험구역 정책, SMS, 관광 콘텐츠, 보고서, 시스템 상태
- 모바일·데스크톱 반응형 UI와 탑승자/운영자 화면 전환

현재 구현은 프론트엔드 데모 데이터로 동작하며 실제 GPS, SMS, 보트 장치 및 Backend 연동은 포함하지 않습니다.
